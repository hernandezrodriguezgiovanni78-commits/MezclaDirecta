## Objetivo
Comprender el funcionamiento interno del algoritmo de ordenamiento externo **Mezcla Directa (Straight Merge)** mediante la implementación de la lógica de intercalación por bloques (intercalarBloques) en Java
## Estructura del proyecto
- src/mezcladirecta/MezclaDirecta.java: Implementación del método intercalarBloques para comparar y mezclar bloques de tamaño L desde dos archivos auxiliares hacia un archivo de salida
- src/mezcladirecta/Main.java: Clase principal que ejecuta la intercalación leyendo f1.txt y f2.txt y generando f0.txt
- f1.txt y f2.txt: Archivos auxiliares de entrada con un número entero por renglón
- f0.txt: Archivo de salida generado al ejecutar el programa
## Cómo compilar y ejecutar en el IDE
1. Abre el proyecto MezclaDirecta en tu IDE de Java (por ejemplo, IntelliJ IDEA).
2. Asegúrate de que f1.txt y f2.txt estén ubicados en la carpeta raíz del proyecto (MezclaDirecta) con un número entero por línea
3. Ejecuta la clase Main (mezcladirecta.Main)
4. Revisa la consola y el archivo f0.txt generado en la raíz del proyecto
